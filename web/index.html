RESEARCH NOTEWhat the current evidence says.

AdaIN produced a usable stylized result in the current local setup at 512 px, with a measured runtime of 0.8758 s and 147.68 MB peak GPU memory.

AdaIN style strength was tested at five alpha values from 0.00 to 1.00. Peak GPU memory remained constant at 147.68 MB across the tested values, while measured runtime ranged from 0.2566 s to 0.4021 s.

Johnson is wired end-to-end, but its current checkpoint was trained only as a pipeline validation run on 200 CIFAR-10 images, so its output is documented as a limitation rather than presented as a quality result.
