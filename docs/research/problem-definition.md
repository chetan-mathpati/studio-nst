# Problem Definition

Neural Style Transfer allows the visual structure of one image to be combined with the appearance characteristics of another.

The engineering problem is not simply producing a stylized image. A practical system must balance:

- visual quality,
- inference time,
- memory usage,
- resolution,
- controllability,
- reproducibility,
- hardware constraints.

Studio NST studies these trade-offs across multiple NST paradigms rather than treating style transfer as a single algorithm.
