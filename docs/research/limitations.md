# Limitations

Current limitations include:

- A 4 GB GPU constrains resolution and batch size.
- Visual quality assessment is partly subjective unless a validated metric is introduced.
- Different NST methods may have different training requirements, making a fair comparison non-trivial.
- Runtime measurements depend on hardware, software versions, warm-up state, and implementation details.
- A small image set cannot establish broad generalization.

These limitations should remain explicit in the final report.
