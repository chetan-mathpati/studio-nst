# Engineering Decisions

## D001 — Research-first repository

The project is structured around reproducible experiments before the frontend. This keeps implementation claims tied to measurable evidence.

## D002 — CUDA when available

The implementation automatically selects CUDA when PyTorch reports a usable NVIDIA GPU, otherwise it falls back to CPU.

## D003 — No fabricated benchmarks

Benchmark tables remain empty until generated by actual runs.

## D004 — Course repositories as references, not implementation templates

The project architecture, documentation, experiments, and UI are independently designed.
